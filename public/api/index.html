Авторизация

Базовый адрес: https://urbanluxe.cc/api/v1. Все ответы — JSON: {"ok":true,"data":…} или {"ok":false,"error":{"code","message"}}.

Ключ выдаёт администратор организации в PMS (раздел «Интеграции»). Два типа ключей:

ТипГде использоватьПрава
sk_live_… секретныйТолько на сервере (CRM, бэкенд сайта). Не вставляйте в HTML.Настраиваются: чтение, брони, отмена, управление
pk_live_… публичныйВ браузере: виджет, JS на сайте. Запросы с любого домена (CORS).Чтение + создание заявок (status=request)
curl https://urbanluxe.cc/api/v1/me \
  -H "Authorization: Bearer sk_live_XXXXXXXX"

Лимит: 120 запросов в минуту на ключ (429 rate_limited). Даты везде в формате YYYY-MM-DD, цены в USD, часовой пояс объектов — Asia/Tashkent.

Брони

POST/bookings — создать заявку или бронь

curl -X POST https://urbanluxe.cc/api/v1/bookings \
  -H "Authorization: Bearer sk_live_XXXXXXXX" -H "Content-Type: application/json" \
  -d '{
    "apartment_id": "nest_325",
    "check_in": "2026-11-05", "check_out": "2026-11-08",
    "guest": { "name": "Иван Петров", "phone": "+998901234567", "email": "ivan@mail.com", "telegram": "@ivan" },
    "guests_count": 2,
    "status": "request",
    "external_ref": "order-10452",
    "notes": "Поздний заезд",
    "total_price": 440
  }'
ПолеОписание
statusrequest — заявка, подтверждает менеджер в PMS (по умолчанию); confirmed — сразу подтверждённая бронь (если у вас своя оплата на сайте). Публичный ключ — только request. В обоих случаях даты удерживаются сразу и закрываются на всех площадках.
total_priceНеобязательно. Если не передать — считается по правилам PMS.
external_refВаш номер заказа — вернётся в вебхуках и в карточке брони.

Ответ 201 — объект брони. Если даты заняты — 409 dates_taken.

{"ok":true,"data":{"id":"64d0cac7-…","ref":"UL-261105-K7PQ","apartment_id":"nest_325","status":"request",
  "check_in":"2026-11-05","check_out":"2026-11-08","nights":3,"guest":{"name":"Иван Петров","phone":"+998901234567",…},
  "guests_count":2,"total_price":440,"currency":"USD","source":"api","channel":"partner-site","external_ref":"order-10452",
  "created_at":"2026-10-16T09:12:00Z","updated_at":null,"cancelled_at":null}}

GET/bookings/{id}

Бронь по id (публичный ключ видит только свои заявки).

GET/bookings?from&to[&status]

Брони по вашим квартирам за период (только секретный ключ, до 500).

POST/bookings/{id}/cancel

Тело: {"reason":"…"}. Отменять можно брони, созданные через API вашей организации; с правом manage — любые брони ваших квартир. Заехавшего гостя отменить нельзя (409 bad_status).

PATCH/bookings/{id} — изменить бронь

Только секретный ключ; свои брони или право manage. Поля (любые из): check_in, check_out, apartment_id, guest{name,phone,email,telegram,whatsapp}, guests_count, total_price, prepaid, notes, arrival_time, departure_time, external_ref, status (request | confirmed; отмена — через /cancel). Пересечение дат → 409 dates_taken, отменённая или заехавшая бронь → 409 bad_status.

POST/apartments — завести/привязать квартиру (для CRM и PMS клиентов)

Право manage, секретный ключ. Тело: {"external_ref":"id в вашей системе","name":"U-51","complex":"U-Tower","address":"…","rc_id":369869,"floor":5,"max_guests":2,"rooms":"Студия","is_active":true}. Повторный вызов с тем же external_ref обновляет название/активность. Если rc_id (объект RealtyCalendar) уже известен PMS как общая квартира — она привязывается к вашему external_ref, а не создаётся заново. ЖК создаётся при отсутствии. Ответ: {"id":"utower_51","created":true,"linked_existing":false,"complex":"U-Tower"}. В вебхуках брони приходит apartment_external_ref.

Вебхуки

В разделе «Интеграции» укажите URL (https) и события. При каждом событии по бронями ваших квартир — откуда бы они ни пришли (ваш сайт, Booking.com, Airbnb, вручную в PMS) — мы отправим POST с JSON:

POST https://your.site/hooks/urbanluxe
X-UL-Event: booking.created
X-UL-Delivery: 1042
X-UL-Signature: sha256=3f1b…

{"id":1042,"event":"booking.created","created_at":"2026-10-16T09:12:01Z","data":{ …объект брони, как в /bookings… }}
СобытиеКогда
booking.createdНовая бронь или заявка
booking.updatedИзменились даты, квартира, статус (подтверждена, заехал, выехал), цена или данные гостя
booking.cancelledОтмена
pingПроверка из PMS

Отвечайте 2xx в течение 8 секунд. Иначе повторы через 1, 5, 30 и 120 минут (до 5 попыток), затем доставка помечается как неуспешная — её можно повторить вручную в PMS.

Проверка подписи

// Node.js
const crypto = require('crypto');
function verify(rawBody, header, secret) {
  const expected = 'sha256=' + crypto.createHmac('sha256', secret).update(rawBody).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(header || ''));
}

// PHP
$expected = 'sha256=' . hash_hmac('sha256', file_get_contents('php://input'), $secret);
$ok = hash_equals($expected, $_SERVER['HTTP_X_UL_SIGNATURE'] ?? '');
Подпись считается по сырому телу запроса (до разбора JSON). Секрет виден в «Интеграциях», его можно перегенерировать.

Виджет бронирования

Готовый блок «даты → свободные квартиры с фото и ценой → заявка» одной строкой. Нужен публичный ключ.

<div id="booking"></div>
<script src="https://urbanluxe.cc/widget.js" data-key="pk_live_XXXXXXXX" data-target="#booking" data-lang="ru"></script>
АтрибутОписание
data-keyПубличный ключ (обязательно)
data-targetCSS-селектор контейнера; без него виджет встаёт сразу после тега script
data-langru (по умолчанию) или en
data-apartmentsПоказывать только эти квартиры: id1,id2

Стили виджета изолированы классами ulw-*; цвета кнопок можно переопределить своим CSS (.ulw button{background:#…}). Заявки приходят в PMS как заявки с сайта, менеджер подтверждает — гость получает письмо.
